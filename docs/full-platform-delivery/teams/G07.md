## G07-01｜二维码解码与安全深链

分支：`feat/FP-G07-01`；波次：W2；硬依赖：G00-02、G00-03。

交付文件/模块（计划）：`crates/features/discovery/src/qr`。接口：scan.decode；deeplink.resolve；qr.render。

**代码实现要求**

1. 选ZXing-C++或rqrr并核文件许可，禁止随机方格二维码。
2. 限定payload长度、scheme、域和签名。
3. 好友/群/支付/小程序码分型解析，支付必须二次确认。
4. 图片识码、相机帧、闪光灯是实际PlatformPort操作。

**验收要求**

打印/另一屏幕实际扫出；恶意URL不自动执行；过期/篡改/重复支付码失败；弱光旋转大图有预算。

还必须附：成功/空结果/参数错误/未授权/超时或断网/取消用例；写操作重复提交用例；涉及数据库时给迁移草稿与回滚兼容说明；涉及个人数据时给最小权限与日志脱敏证据。测试使用真实域实现；mock只用于供应商故障注入或在上游卡尚未合入时的并行开发，不能用mock通过最终集成验收。

## G07-08｜位置消息、POI、导航与实时位置共享

UI v2新增卡；分支`feat/FP-G07-08`，波次W2/W3。

硬依赖：G07-03、G03-01；集成验收依赖：G12-05、G13-06、G04-05。可按冻结fixture开发，真实上游未合不得验收。

唯一修改模块：`crates/features/discovery/src/location_share`；接口：location.search/send/share.start/join/update/leave/stop；LocationSession。

**代码实现要求**

1. 真实地图/POIProviderPort与坐标系契约，明确WGS84/GCJ02等边界不可盲混坐标。
2. 发送位置是固定快照消息引用，G03负责投递，G07负责会话与位置权限。
3. 实时共享必须显式加入、仅授权会话成员可见，带seq/TTL/更新频率/精度/退出和单会话上限。
4. 后台定位按Android/iOS权限和生命周期要求，不承诺无限后台存活。
5. 断网显示最后位置时间并停止伪更新。
6. 地图导航经受限OS深链或真实导航组件，撤回后清停止任务并逐请求拒绝旧会话。
7. 精确位置不进入公开附近索引。

**验收**

两真机真实移动后位置变化；停止/退群/撤权限后对端不再能读新位置；模拟器只能补自动测试不替真机；POI搜索不是静态附近列表，地图错误/坐标偏差有回归。

公共清单/锁/router/迁移编号交G00，生成绑定交G01；禁止越过owner修改其他组文件。PR附entry_id/action_id、云CI/真机证据、来源许可、迁移及回滚兼容说明；不得以mock/toast标完成。

## G07-09｜个人名片二维码、样式、保存分享与撤销

UI v2新增卡；分支`feat/FP-G07-09`，波次W2/W3。

硬依赖：G07-01；集成验收依赖：G02-02、G04-05、G13-06。可按冻结fixture开发，真实上游未合不得验收。

唯一修改模块：`crates/features/discovery/src/contact_qr`；接口：contact.qr.create/resolve/rotate；ContactCardPayload。

**代码实现要求**

1. 调用成熟编码器生成标准码，payload是可撤销的opaque profile capability或受控深链，不含手机号token等敏感数据。
2. 支持春日绿/墨绿/暖阳/雾蓝四样式，但码的quiet zone/对比度/纠错和logo遮挡必须通过真实解码测试。
3. 保存是系统相册/下载实际写入，分享走受控系统分享或好友消息。
4. 扫码进入真实资料再发好友申请，不能扫码即自动加好友。
5. 身份/实名徽标只能来自已验证字段，旧码可轮换撤销。

**验收**

四种样式在手机相机/相册/桌面截图中可解码；保存图片重开可扫；撤销后旧码不可加人；二维码不授予读取全部资料权限，好友申请仍走G02权限与限流。
