## G02-01｜账号会话与设备生命周期

分支：`feat/FP-G02-01`；波次：W1；硬依赖：G00-02、G00-03。

交付文件/模块（计划）：`crates/features/identity/src`。接口：identity.login/logout/session.list/session.revoke/device.list。

**代码实现要求**

1. 复用token auth/revocation，补设备标识、刷新轮换/重放检测、登录限速。
2. 敏感操作step-up、找回流程不泄漏账号存在。
3. 登出撤销指定会话并发事件清缓存。

## G02-06｜手机号验证码、登录方式与协议同意记录

UI v2新增卡；分支`feat/FP-G02-06`，波次W2/W3。

硬依赖：G02-01、G00-03；集成验收依赖：G12-06、G10-06。可按冻结fixture开发，真实上游未合不得验收。

唯一修改模块：`crates/features/identity/src/login_challenge`、`crates/features/identity/src/consent`；接口：identity.login.challenge/verify/methods；ConsentReceipt。

**代码实现要求**

1. 手机号E.164规范化、国家码选择和枚举防护。
2. 短信挑战随机生成，哈希存储，绑定phone+purpose+device，TTL/尝试次数/每号每IP限流、重发真实倒计时、防并发复用。
3. 只有服务端验证成功才签发会话，勾选协议不是认证。
4. 协议版本/同意时间/用途落审计。
5. 邮箱/自有账号密码沿用身份规则，QQ等外部OAuth必须官方凭据与state/PKCE验证，真实微信账号登录另列外部阻塞，不能声称自有账号就是微信账号。
6. 语言切换用真实locale资源，测试验证码只允许隔离dev profile，生产禁固定万能码。

**验收**

错码/过期/重放/爆破/响应丢失/并发验证测试；重发后旧码失效；不泄漏手机号是否注册；凭据日志脱敏；供应商sandbox成功及失败证据齐全，未开通不计全范围完成。

公共清单/锁/router/迁移编号交G00，生成绑定交G01；禁止越过owner修改其他组文件。PR附entry_id/action_id、云CI/真机证据、来源许可、迁移及回滚兼容说明；不得以mock/toast标完成。

## G02-07｜桌面扫码登录、手机授权与设备信任

UI v2新增卡；分支`feat/FP-G02-07`，波次W2/W3。

硬依赖：G02-06；集成验收依赖：G07-01、G10-06、G12-06。可按冻结fixture开发，真实上游未合不得验收。

唯一修改模块：`crates/features/identity/src/qr_login`；接口：identity.qr_login.create/scan/approve/reject/poll；DeviceAuthorization。

**代码实现要求**

1. 桌面生成短期单次challenge，二维码含公开challenge而非session token。
2. 待登录设备生成临时密钥/PKCE绑定，服务端保存校验摘要。
3. 已登录手机扫码只到SCANNED，显示桌面OS/设备/位置线索后用户明确批准才到APPROVED。
4. 桌面提交绑定证明原子exchange为设备会话，手机拒绝/过期/退出后失败。
5. 二维码刷新撤销旧challenge。
6. 设备撤销与跨端密钥信任分开，扫码登录不能静默信任全部历史密钥。
7. 自动登录仅使用可撤销的设备凭据进OS安全存储，默认最近7天同步是查询范围而非删除旧消息。

**验收**

真实手机扫真实桌面码完成授权；复制二维码的第三方不能盗领会话；两桌面竞领、旧码重放、手机撤销和刷新均失败封闭；扫码点击演示按钮不得成为生产认证路径。

公共清单/锁/router/迁移编号交G00，生成绑定交G01；禁止越过owner修改其他组文件。PR附entry_id/action_id、云CI/真机证据、来源许可、迁移及回滚兼容说明；不得以mock/toast标完成。
