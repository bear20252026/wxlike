## OSV 联网路径复核

按 [OSV batch 文档](https://google.github.io/osv.dev/post-v1-querybatch/) 和
[OSV 生态规范](https://ossf.github.io/osv-schema/) 修正旧实现：

- Cargo / npm / Dart 分别按 crates.io / npm / Pub 查询；同名包按生态隔离，镜像不伪装成 crate。
- 按查询位置合并分页，只重查仍有 token 的查询；响应缺项、循环 token、分页超预算均为数据错误。
- 同一公告影响多个版本时保留每个受影响版本，详情按 id 缓存，不再按全局 id 丢掉后续版本。
- 详情断网或 id 不符不能当作完成；unsound 不再被当作“无人维护”降为 Low。
- 只采用上游明确等级，不用自制粗略 CVSS 向量分档；实际政策 `unverified=block`，未知等级必须复核后才可冻结。
- 10 项新增 OSV 接线回归通过；此处网络 mock 仅用于请求契约、分页和失败注入，不作为真实联网扫描通过证据。
